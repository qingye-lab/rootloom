# Rootloom 4.1.0 Core Reset evaluation

Status: **formal behavioral gate not accepted**.

The retained 126-run v2 result proves complete candidate task success and exact 4.1
Skill/Reference routing, but it fails two repository-owned efficiency thresholds. It
must not be used to claim that 4.1 has formally passed the complete release rubric.

## Formal gate result

The structural gate passed:

- four public Skills;
- Change Skill size 4,711 bytes versus 8,296 bytes in 3.4;
- 43.21% structural Change context reduction.

The behavioral gate failed:

1. Tier 0/1 activated context averaged 5,995 bytes versus 8,296 bytes in 3.4, a
   27.74% reduction rather than the required 30%.
2. Routine uncached input averaged 27,841.62 tokens versus 25,079.05 in 3.4, a
   1.1102 ratio, so it increased 11.02% instead of decreasing.

The remaining formal comparisons passed:

| Comparison | Ratio | Required |
| --- | ---: | ---: |
| Routine elapsed geometric mean | 0.7834 | `< 1.0` |
| Evidence elapsed geometric mean | 0.6063 | `< 1.0` |
| Governed elapsed geometric mean | 0.6065 | `≤ 1.10` |
| Guidance/Setup elapsed geometric mean | 0.8536 | `≤ 1.10` |
| Evidence input tokens | 0.4909 | `< 1.0` |
| Direct command count | 0.9231 | `≤ 1.0` |

The deterministic 95% bootstrap interval for the routine elapsed mean ratio was
`[0.7296, 0.9813]`.

## Release effect

`.github/workflows/release-evidence.yml` runs the retained result through
`make core-reset-release-eval` on version tags. With this candidate the job fails
closed on the two efficiency errors above. This is intentional: the architecture,
quality, and route evidence may be used on their own terms, but the complete formal
efficiency claim and release acceptance remain blocked.
