# Rootloom 4.1.0 Core Reset evaluation

Status: **formal behavioral gate not accepted**.

The retained 126-run v2 result now binds the token-governed Core tree. The change fixes
both previous efficiency failures: ordinary Change context is 46.25% smaller than 3.4
and routine uncached input is 11.81% lower. Task success remains 42/42.

The complete gate still fails closed because one Governed run omitted two required
References and two quality cells scored slightly below their 3.4 baseline. Those runs
were retained rather than selectively replaced, and no threshold was weakened.

- Change Skill size 4,459 bytes versus 8,296 bytes in 3.4;
- 46.25% ordinary Change context reduction;
- Direct and Scoped activate no Reference, while Governed and Evidence retain detailed
  Reference routes.
