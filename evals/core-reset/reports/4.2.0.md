# Rootloom 4.2.0 Core Reset evaluation

Status: **formal behavioral gate accepted**.

The retained 126-run v2 result binds the Rootloom 4.2 Core tree and passes the
structural and behavioral release gates. The candidate completes 42/42 tasks, routes

root-cause, Governed, and Evidence score equals the 3.4 baseline.

## Scoring corrections

The release run exposed three mechanical boundary defects, all corrected without
weakening outcome gates:

- a successful shell loop using an explicit Skill `references/` directory and Markdown
  basenames now counts the files it actually read;
- bounded migration wording such as `byte-for-byte no-op` and `does not rewrite v2`
  counts as the same idempotency claim;
- elapsed ratios use only repetition pairs where both variants complete the task.
  Task-success regression remains a separate hard failure, so a fast failed baseline
  exit cannot be scored as an efficiency advantage.

The final Change rerun also confirms that batching Direct reads and final checks reduces
the six Direct rows from 43 commands in the superseded candidate to 27, versus 40 for
the interleaved 3.4 baseline.
